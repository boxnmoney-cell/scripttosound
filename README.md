# Script to Sound — новая версия

Локальное приложение для видео → анализа событий → редактируемого сценария →
озвучки ElevenLabs → MP4 и SRT. Интерфейс открывается в браузере.

## Что реализовано

- Отдельный выбор языка сценария и озвучки. По умолчанию оба — Português (Brasil).
  Также доступны русский, английский, испанский (Мексика / Латинская Америка),
  вьетнамский, португальский (Португалия), немецкий и французский.
- Перевод уже созданного сценария без повторного анализа видео.
- Русский перевод для проверки смысла.
- Редактируемые профили Falling Pickaxe и Viper Royale, события с доказательствами,
  просмотр соответствующего момента видео, ручное исправление событий.
- Проверка сценария на соответствие подтверждённым событиям, запрет вымышленных
  результатов и вводящих в заблуждение финансовых обещаний. Это проверка моделью,
  она может ошибаться и не гарантирует соответствие правилам платформ.
- Редактор реплик и временных интервалов. Генерация нового варианта с пожеланием.
- Выбор голосов из аккаунта или ввод точного Voice ID. Загрузка списка моделей
  ElevenLabs; ID не угадывается по названию. Можно сохранить голос для каждого языка.
- Синтез по смысловым отрезкам, кэширование неизменённых реплик, паузы,
  ускорение речи максимум на 12%. Если речь длиннее — программа предлагает сократить
  конкретную реплику или изменить её время. Автоматического обрезания слов нет.
- Экспорт MP4 без обрезки конца, WAV, TXT, JSON и SRT по репликам.
- Локальная история проектов и кэш анализа, учитывающий модель, правила и кадры.

## Установка в Windows

1. Установите **Python 3.12 или новее** с официального python.org. Включите Python Launcher.
2. Установите **FFmpeg с ffprobe** и добавьте каталог `bin` в PATH.
   Официальная страница: https://ffmpeg.org/download.html .
   Проверка в новом терминале: `ffmpeg -version` и `ffprobe -version`.
3. Распакуйте архив в отдельную папку. Запустите **setup.bat**.
4. Откройте созданный `.env` локально и заполните свои API-ключи. Можно вместо
   этого вводить их в поля приложения на время сессии. Значения ключей никому не отправляйте.
5. Запустите **start_app.bat**. Путь к пользовательской папке в коде не зашит.

Подписка/доступ к ElevenLabs не заменяет OpenAI API: для анализа и текста нужен
отдельный доступ к OpenAI API и доступные кредиты. ElevenLabs синтез расходует кредиты аккаунта.
Кнопки, обращающиеся к API, запускают платные операции. Кэшированные ответы используются повторно.

## Первый запуск с GPT-5.5 и ключами

По умолчанию GPT-5.5 используется и для анализа кадров, и для сценария.
Самый простой способ подключения — открыть в боковой панели «Ключи и модели»
и вставить ключи в поля «OpenAI API key» и «ElevenLabs API key». Ключи из полей
действуют в текущей сессии; отправлять их в чат не нужно.

Для сохранения между запусками заполните локальный `.env` в папке приложения:

```dotenv
OPENAI_API_KEY=ваш_ключ_OpenAI
ELEVENLABS_API_KEY=ваш_ключ_ElevenLabs
OPENAI_VISION_MODEL=gpt-5.5
OPENAI_TEXT_MODEL=gpt-5.5
```

После изменения `.env` закройте приложение и запустите `start_app.bat` заново.
Если используется `.env` от старой версии, замените в нём обе модели на `gpt-5.5`:
установщик сохраняет существующий файл и его настройки.

Ключ OpenAI создаётся на https://platform.openai.com/api-keys .
В ElevenLabs откройте Developers → API Keys; ключу нужны права на синтез речи,
чтение голосов и моделей. Точные названия разрешений зависят от интерфейса аккаунта.

В приложении нажмите «Загрузить мои голоса и модели», выберите голос и модель
ElevenLabs. Затем загрузите видео и нажмите последовательно «Создать / открыть
проект этого видео», «Проанализировать видео» и «Создать новый вариант».
Отредактируйте сценарий при необходимости и сохраните правки. «Создать озвучку»
создаст аудио прямо в приложении, а «Собрать MP4» объединит его с видео.

Для первого теста используйте короткий ролик: доступ к GPT-5.5, расходы и качество
ответов нужно проверить с вашим аккаунтом. Реальные запросы этой версии через
ваши ключи при разработке не выполнялись.

## Linux / macOS

Установите Python 3.12+ и FFmpeg, затем из каталога приложения:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env  # только если своего .env ещё нет
bash start_app.sh
```

## Голос André — Natural excitement

Нажмите «Загрузить мои голоса и модели». Если голос доступен в аккаунте, выберите
его из списка. Иначе добавьте его в свою библиотеку ElevenLabs или скопируйте точный
Voice ID оттуда. Имя на скриншоте не позволяет надёжно установить ID.
Выберите нужную модель из ответа API. Программа не предполагает, что `eleven_v4`
доступна конкретному аккаунту. Произношение и подходящий акцент зависят также от голоса;
проверяйте аудио на каждом выбранном языке.

## Рабочий процесс

1. Выберите игру, загрузите MP4/MOV/MKV/AVI/WebM, создайте проект.
2. Выберите языки сценария и озвучки. Их можно менять позднее.
3. Выполните анализ. Для динамичных эпизодов используйте подробный режим.
4. Просмотрите события. `uncertain` не используется при генерации сценария.
   Исправленные вручную события помечаются `user`; ответственность за эти факты у редактора.
5. Создайте сценарий, измените текст и время реплик, сохраните изменения.
   Для другой языковой версии можно перевести готовый текст.
6. Если язык озвучки отличается, отдельно подготовьте и проверьте её текст.
7. Выберите голос и модель, создайте озвучку. При слишком длинном фрагменте
   сократите его; остальные удачные фрагменты останутся в кэше.
8. Прослушайте, скачайте WAV/SRT или соберите MP4. Исходный звук по умолчанию выключен:
   при его включении сохранится и старая озвучка, если она была в исходном ролике.

## Ограничения первой версии

- Присланные для разработки два ролика превышают лимит передачи в среду анализа
  (32 МиБ каждый), поэтому они **не просмотрены и не использованы для проверки**.
  Это ограничение передачи вложений, а не приложения: локально оно принимает до 500 МБ.
  Длительность ролика ограничена 10 минутами; длинные видео лучше разделить на раунды.
- Профили игр предварительные: основаны на примере исходного приложения и общих
  требованиях к доказательствам, а не на просмотре этих двух роликов.
- Анализ использует выборку кадров, не все кадры и не исходную аудиодорожку.
  Быстрые события могут пропускаться. Встроенные субтитры не считаются источником фактов,
  но могут влиять на модель; нужна проверка результата человеком.
- Озвучка по отдельным отрезкам может иметь различия интонации между фрагментами.
  Генерация по конкретному голосу и качество разных языков требуют проверки через API.
- SRT синхронизирован по репликам, без пословной подсветки. Вшивания новых субтитров,
  автоматического удаления старых субтитров и отделения старого голоса от игровых
  звуков в этой версии нет. SRT можно открыть в CapCut или другом редакторе.
- Локальные проверки и медиаэкспорт проверяются автоматически. Реальные запросы
  OpenAI/ElevenLabs без ваших ключей не выполнялись. Тесты HTTP используют подставные ответы.
- Фильтра «обхода модерации» и гарантии охватов нет. Правила платформ нужно проверять
  для содержания ролика, рекламы и ссылки назначения. Автоматический призыв перейти
  на азартную игру по умолчанию не создаётся.

## Данные и ключи

Проекты, видео, кадры, сценарии и аудиокэш сохраняются в `data/` на вашем компьютере.
При анализе выбранные кадры отправляются OpenAI, при синтезе текст — ElevenLabs.
Исходный звук в OpenAI не отправляется. API-ключи не записываются в проекты и кэш;
локальный `.env` и `data/` исключены из Git. Не выкладывайте их в общий доступ.
Для удаления проекта закройте приложение и удалите соответствующую папку из
`data/projects/`. Интерфейс предназначен для одного пользователя на локальной машине.

## Проверка разработки

Проверено в текущей среде Linux с Python 3.12: 16 тестов, запуск через
`start_app.sh`, HTTP-ответ интерфейса и проверка зависимостей. Windows BAT-файлы
подготовлены, но запуск в Windows здесь не выполнялся. Подробные правила:
[RULES.md](RULES.md).

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Тесты проверяют языки интерфейса, перевод без изменения событий, отклонение
неподтверждённых фактов, сброс устаревшего аудио, кэш API, отсутствие автоматического
повтора платного синтеза и реальный FFmpeg-экспорт на искусственном тестовом видео.
